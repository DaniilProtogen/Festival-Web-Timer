## Features

* Timer synchronization between all connected devices via WebSocket (Socket.IO)

* Timer control from any device

* Automatic fullscreen mode when the timer starts

* GrandMA3-style timer with DSEG7 Modern font

* Simple, minimalist, and responsive design

* Built with Node.js and Express, easy to deploy locally or on a server
